Estoy trabajando en el prototipo visual desde cero para una app móvil Flutter llamada **Inventory Control Mobile**.

Quiero que me ayudes a crear un prompt final para **Figma Make**. No quiero reutilizar el prototipo anterior ni parcharlo. Quiero empezar el diseño visual desde cero, pero manteniendo el alcance funcional que ya definí.

## Contexto del proyecto

La app resuelve una problemática de una pequeña cadena de tiendas locales que actualmente controla inventario mediante hojas de cálculo y registros manuales. Esto genera inconsistencias en existencias, pérdidas de productos y poca trazabilidad sobre qué colaborador realizó cada movimiento.

La app será desarrollada en **Flutter** y usará un backend con **Firebase**.

Servicios Firebase propuestos:

* Firebase Auth.
* Cloud Firestore.
* Firebase Storage.
* Firebase Cloud Messaging.

La app debe permitir:

* Autenticación de usuarios.
* Gestión CRUD de productos.
* Gestión simple de sucursales.
* Visualización de stock por sucursal.
* Registro de entradas y salidas de inventario.
* Validación de salidas contra stock disponible.
* Historial de movimientos.
* Búsqueda y filtros.
* Imágenes de productos.
* Alertas o notificaciones de bajo stock.
* Almacenamiento local básico para sesión, preferencias o sucursal seleccionada.

## Cambio funcional importante

Antes el prototipo trataba la sucursal como algo secundario. Ahora eso cambió.

La sucursal debe ser parte visible del flujo.

El modelo funcional correcto es:

Producto + Sucursal = Stock disponible.

Movimiento = Producto + Sucursal + Usuario + Cantidad + Motivo.

El stock no se edita directamente en el producto. El stock se actualiza únicamente mediante movimientos de inventario.

## Reglas visuales globales

* Todas las pantallas deben ser dark premium.
* No usar fondos blancos.
* No usar cards blancas.
* No mezclar pantallas claras con oscuras.
* Usar degradados sutiles para evitar negro plano.
* Usar superficies oscuras con buen contraste.
* Usar bordes muy sutiles, no cards muy marcadas.
* Usar sombras o contraste de superficie para dar profundidad.
* Usar teal como acento principal de marca.
* Usar colores funcionales solo para estados.
* Mantener buena legibilidad.
* Mantener diseño compacto.
* Usar componentes consistentes en todas las pantallas.
